## 1.3 Hello, Cargo!
- rust compilation requires gcc ¯\_(ツ)_/¯
- `cargo build` = cargo builds an application
- `cargo run` = cargo builds & runs application
	- cargo will only recompile if main.rs is changed.
- `cargo check` = checks if cargo can compile
